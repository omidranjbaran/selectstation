# 🧭 مسیر‌یاب دانشجویی (Student Route Selector)

پروژه‌ای Full Stack با استفاده از **React + Django** برای انتخاب مسیر تردد دانشجویان به دانشگاه و تحلیل داده‌های مسیر توسط مدیر سیستم.

---

## 📝 توضیح کلی

این پروژه به دانشجویان اجازه می‌دهد تا مسیر (ایستگاه) رفت‌وآمد خود به دانشگاه را انتخاب کنند. مدیر سیستم می‌تواند تحلیل کند که کدام مسیرها بیشترین استفاده را دارند و بر اساس آن تصمیم‌گیری کند.

---

## ⚙️ تکنولوژی‌ها (Tech Stack)

- 🌐 **Frontend**: React.js
- 🎨 **Styling**: TailwindCSS
- 🔐 **Authentication**: JWT (JSON Web Tokens)
- 🧠 **Backend**: Django + Django REST Framework
- ⚡ **API Communication**: Axios
- 📦 **Package Manager**: npm / pip

---

## ✨ قابلیت‌ها

### 🎓 داشبورد دانشجو:
- نمایش لیست ایستگاه‌ها روی نقشه
- انتخاب ایستگاه برای مسیر روزانه
- احراز هویت با JWT

### 🛠️ داشبورد مدیریت:
- مشاهده لیست ایستگاه‌ها
- نمایش تعداد دانشجویان هر ایستگاه
- تحلیل مسیرهای پرکاربرد
